# 2-C 동작·화면 확인 기록

실제 백엔드(Flask, 시드 데이터)와 프론트 개발 서버(Vite proxy)를 붙여 Chromium(Playwright)으로 확인했어요. 화면은 390x844(`m-`)와 1440x900(`d-`) 두 크기로 캡처했어요.
시드: `python scripts/seed_demo.py --out <DATA_DIR>/app.db`, 슈퍼관리자: `DATA_DIR=<DATA_DIR> flask --app wsgi.py create-superadmin --username root --password <임시값>`. 나머지 계정은 화면에서 발급했어요.
구동 환경: `SESSION_COOKIE_SECURE=0 CORS_ORIGINS=http://localhost:5173 TRUSTED_PROXY_HOPS=0 VISITOR_RESERVE_LIMIT=1000 VISITOR_LOOKUP_LIMIT=1000 LINK_MISS_LIMIT=1000`(한 IP 에서 반복 확인하느라 방문객 제한만 높임), 프론트 `VITE_API_TARGET=http://localhost:5005 npm run dev`.

## 화면 규칙 검토

| 항목 | 결과 | 비고 |
|------|------|------|
| 390px 가로 스크롤 없음(긴 이름 포함) | 통과 (수정 2건) | 관리자 18개 화면 + 로그인을 `scrollWidth <= clientWidth` 로 확인. 40자 넘는 부스 이름(공백 없음)·행사 이름 포함. D1, D2 수정 후 모두 통과 |
| 표가 좁은 화면에서 읽히는가 | 통과 (수정 1건) | 칸이 한 글자씩 쪼개져 읽을 수 없었음(D2). 수정 후 긴 값 칸만 줄바꿈, 나머지는 표 영역 안에서 가로 스크롤(키보드 초점 가능) |
| 토큰 색·둥글기·도장·이모지 없음 | 통과(육안) | 주요 캡처를 눈으로 확인. 색만 다른 통계 카드 없음, 숫자 요약은 한 줄 |
| 관리자 재료(잉크 사이드바, `paper-2` 본문, 선택 탭 노랑 밑줄) | 통과 | 1440 은 사이드바, 390 은 상단 막대 + 접히는 메뉴(`m-40-menu-open`) |

## 참고

- 흐름 중간에 찍은 캡처(`d-02-password-forced`, `d-03`, `d-04`, `d-31-super-members-temp-password` 등)는 표 수정 전 화면이에요. 표가 있는 화면 캡처는 수정 뒤 다시 찍은 것이에요.
- 계정 발급 첫 시도는 스크립트 선택자 충돌로 중간에 멈춘 뒤 이어서 확인했어요(발급 자체는 화면에서 이루어졌고, 이후 초기화로 임시 비밀번호 복사를 확인).
- 개발 서버가 보는 IP 는 127.0.0.1 이라 `TRUSTED_PROXY_HOPS=0` 이에요. 운영의 `whoami-ip` 확인은 전환 후 해야 해요.
- 확인 도구(Playwright 스크립트, 임시 DATA_DIR)는 저장소 밖 임시 폴더에 있어요.
